NeetoPlaydash hosts the MCP server. There is nothing to install.

| | |
| --- | --- |
| **Endpoint** | `https://connect.neetoplaydash.com/mcp/messages` |
| **Transport** | HTTP |
| **Authentication** | OAuth, or `Authorization: Bearer YOUR_API_KEY` |

## How each agent connects

| Agent | Sign in with NeetoPlaydash | API key |
| --- | --- | --- |
| Claude, ChatGPT | Yes | No |
| Claude Code, Codex, Cursor, Gemini CLI, VS Code, Windsurf | Yes | Yes |
| Antigravity | Not documented | Yes |

When you sign in, the assistant reaches only the workspaces you approve. An API key reaches the one workspace it belongs to. See [Authentication](/mcp/authentication).

For the setup steps, see [Connect agent](/mcp/connect).
