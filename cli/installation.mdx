---
title: "Installation"
description: "Install the neetoplaydash CLI on macOS, Linux, or Windows."
---

Install the `neetoplaydash` binary with the command for your platform, then [verify it](#verify-the-installation).

<CodeGroup>
```bash macOS
brew trust neetozone/tap
brew install neetozone/tap/neetoplaydash
```

```bash Linux
curl -fsSL https://neeto-downloads.s3.amazonaws.com/cli/NeetoPlaydash/latest/install.sh | sh
```

```powershell Windows
irm https://neeto-downloads.s3.amazonaws.com/cli/NeetoPlaydash/latest/install.ps1 | iex
```
</CodeGroup>

The shell and Windows installers download the latest release for your architecture (`amd64` or `arm64`), extract it, and add `neetoplaydash` to your `PATH`.

## Other install methods

<AccordionGroup>
  <Accordion title="macOS - shell script">
    ```bash
    curl -fsSL https://neeto-downloads.s3.amazonaws.com/cli/NeetoPlaydash/latest/install.sh | sh
    ```

    Installs to `/usr/local/bin` and may prompt for `sudo`. To update a Homebrew installation, run `brew upgrade neetoplaydash`.
  </Accordion>
  <Accordion title="Windows - Command Prompt (CMD)">
    ```cmd
    curl -fsSL https://neeto-downloads.s3.amazonaws.com/cli/NeetoPlaydash/latest/install.cmd -o install.cmd && install.cmd
    ```

    Extracts to `%LOCALAPPDATA%\Programs\neetoplaydash` and adds it to your user `PATH`. This is equivalent to the PowerShell method.
  </Accordion>
</AccordionGroup>

## Verify the installation

Restart your terminal, then run:

```bash
neetoplaydash --help
```

You should see the list of available commands. To check the installed version:

```bash
neetoplaydash version
```

## Upgrade

```bash
neetoplaydash update
```

The command detects how the CLI was installed and runs the matching upgrade: `brew update && brew upgrade neetozone/tap/neetoplaydash` for a Homebrew install, the shell installer for other macOS and Linux installs, and the PowerShell installer on Windows. It prints the command it runs and exits non-zero if that command fails. You can also run the install command for your platform again. See [`neetoplaydash update`](/cli-reference/utility#update).

After an upgrade, re-run `neetoplaydash completion <shell>` and any `neetoplaydash setup` command you use so their files match the new version.

<Tip>
  Next, [sign in](/cli/authentication) to a workspace and run `neetoplaydash doctor`
  to confirm the CLI can reach NeetoPlaydash.
</Tip>
