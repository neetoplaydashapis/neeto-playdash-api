| Flag | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--branch` | `string` |  |  | Filter runs by branch name |
| `--page` | `int` |  | `0` | Page number |
| `--page-size` | `int` |  | `0` | Items per page (max 50) |
| `--status` | `string` |  |  | Filter runs by status (e.g. passed, failed, running) |
